# История версий

Формат: [семантическое версионирование](https://semver.org/lang/ru/). `versionCode` растёт на 1 с каждой
версией и нужен Android для обновления поверх (`adb install -r`).

| Версия | versionCode | Git-тег | Ключевое |
|---|---|---|---|
| 1.3.0 | 4 | `v1.3.0` | Автоматизация установки: экран «Настройка бокса» в приложении и `install.sh` |
| 1.2.0 | 3 | `v1.2.0` | Без root: тайлинг запущенных приложений и закрытие окон через встроенный adb-клиент |
| 1.1.0 | 2 | `v1.1.0` | Путь через root (`su`) для уже запущенных приложений |
| 1.0.0 | 1 | `v1.0.0` | Первая версия: сценарии, виджеты, freeform только при холодном старте |

## 1.3.0 — от 1.2.0

Главное: установка и настройка сведены к «включить отладку по Wi-Fi + одна команда/одна кнопка».

### Добавлено
- **Экран «⚙ Настройка бокса»** (`SetupActivity`): показывает статус (канал adb, право
  `WRITE_SECURE_SETTINGS`, freeform) и кнопкой «Настроить автоматически» сам выдаёт себе право и
  включает freeform через встроенный adb-канал; кнопки «Перезагрузить бокс» и «Открыть настройки разработчика».
- **`install.sh`**: ищет бокс в сети (порт 5555), подключается, ставит APK, выдаёт право, включает freeform,
  запускает приложение; `--reboot` перезагружает бокс. Если `adb` нет, скачивает только `platform-tools`.

### Изменено
- README: «Быстрая установка» (два варианта) вместо шести ручных шагов; ручные шаги сохранены.

## 1.2.0 — от 1.1.0

Главное: **root больше не нужен** для перетайливания уже запущенных приложений.

### Добавлено
- **Встроенный adb-клиент** (`Adb.java`): приложение подключается к adbd бокса на `127.0.0.1:5555`
  (протокол adb, RSA-ключ генерируется при первом запуске) и выполняет команды от shell-пользователя.
  Этого хватает для `am start --windowingMode 5`, `am task resize` и `am stack remove`.
- **Закрытие окон:** кнопка «✕ Закрыть все окна» в приложении и отдельный виджет
  «Мультиокно: закрыть окна» (`CloseWidgetProvider`). Закрывается только окно, приложение не убивается.
- **Автовключение отладки по Wi-Fi после перезагрузки** (`BootReceiver`, право `WRITE_SECURE_SETTINGS`):
  бокс сбрасывает `adb_wifi_enabled` при каждой загрузке, приложение возвращает его само.
- Версия приложения показывается внизу главного экрана.

### Изменено
- Порядок каналов запуска: `su` → adb-shell → прежний путь через `ActivityOptions`
  (последний тайлит только приложения, которые ещё не запущены).
- Границы окон: верх под статус-баром, низ над панелью ◁○□ (сторонний оверлей `nu.nav.bar`, 32 dp,
  константа `OVERLAY_NAV_BAR_DP`).
- Если канал shell доступен, приложение больше не откатывается на старый путь после частичного сбоя.

### Исправлено
- **Apple Music не тайлился, а Навигатор запускался дважды.** У Apple Music случайный `taskAffinity`,
  поэтому поиск задачи по имени пакета в `dumpsys` её не находил. Теперь задача ищется через
  `am stack list` по пакету активности.

### Новые разрешения
`INTERNET` (сокет на localhost), `RECEIVE_BOOT_COMPLETED`, `WRITE_SECURE_SETTINGS` (выдаётся один раз
через `adb shell pm grant`, см. README).

## 1.1.0 — от 1.0.0

### Добавлено
- Путь через root: `su` + `am start --windowingMode 5` + `am task resize` перетайливает уже
  запущенные приложения (обычное приложение этого сделать не может — `setLaunchBounds` для
  существующей задачи игнорируется).
- Фолбэк на `ActivityOptions`, если `su` недоступен.

## 1.0.0

- Сценарии (две программы + раскладка 50/50, 65/35, 35/65, 60/40, 40/60), виджеты-плитки.
- Freeform при холодном старте через `setLaunchWindowingMode` (работает при `targetSdkVersion=25`).
